This is a web page for a summer school for lattice QCD in Japan

DATE: 2024/9/9-2024/9/13 

https://akio-tomiya.github.io/latticeschool2024/

Note (November 2026): the Julia examples in this repository (tutorial3.jl, heatbath.jl, su3_polyakov_loop.ipynb) use the pre-v1 API of Gaugefields.jl. For new code, use the v1 API shown in the [Gaugefields.jl README](https://github.com/akio-tomiya/Gaugefields.jl); the [Legacy API page](https://akio-tomiya.github.io/Gaugefields.jl/v1/legacyapi/) maps old calls to v1.
